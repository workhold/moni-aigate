# 030 集成合同

本片只使用当前完整迁移计划；缺少别名表不能继续旧目录或旧解析。别名写入沿用 pricing operation 的不可变身份、管理员复验、事务锁及审计；原 operation 在退役后仍返回原回执，不以可变别名行作为重放依据。别名创建者、创建时间保持不变，退役 operation 单独冻结退役操作者和原创建事实。

组价编译在一个事务内选择默认价格。先按排序后的 model ID 取得 SHARE 锁，再锁价格组；先关闭查询游标，再在同一事务核对不可变 schema。所有模型共享一个选价时刻，不嵌套使用忙连接。

`group_price.compile` 的指纹按既有 pricing framing 追加倍率原文、规范模型数组、UTC 六位微秒时间、规范预期版本对象。数组为去重后的 UUID 字典序；对象按 UUID 字典序、无空格 JSON 编码；未提供对象使用 NULL frame，显式空对象使用 `{}`，两者不同。Go、SQL、TS 必须一致，不使用 JSONB 默认格式化文本作为规范字节。

每个 operation 允许 1–100 个价格版本；普通发布仍恰好一个。数据库同时验证结果中的模型、基准版本、基准费率、倍率计算结果与实际新版本一一对应。任一缺价、原价变化、溢出、缺行、错误归属或审计故障整批回滚。单个 operation 结果限额为 64 KiB，仍不允许任意增长；该上限适用于编译种类，其他种类保持 8 KiB。

预览不写 operation 或价格；发布重放不重新读当前默认价。编译后的费率是不可变绝对有理费率；运行时不再乘倍率。
