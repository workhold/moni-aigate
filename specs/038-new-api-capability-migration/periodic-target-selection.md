# 038 后续修复：周期预算目标选择入口

2026-11-18；状态：实施合同。修复平台导航 `/platform/periodic-budget` 必然进入“预算目标无效”的独立 UX 问题，不改变支付、预算账务或 PR-3 认证范围。

## 1. 现状与目标

`parsePeriodicTarget` 要求平台路径恰好携带一个 `tenant=<uuid>` 或 `procurement=<uuid>`，而平台侧栏只提供裸路径，因此首次进入必然失败。目标是让裸路径成为可完成工作的入口，同时保持严格目标身份和现有预算合同。

## 2. 状态机与导航

- 平台裸路径且没有查询串：显示“选择预算目标”，不显示错误告警。
- 平台查询串为空之外的任何无效形式、重复参数、未知参数、非规范 UUID：继续显示“预算目标无效”，不得自动猜测或替换目标。
- 客户/采购深链：继续解析到原 `PeriodicTarget` 和 `PeriodicBudgetPanel`，预算读写权限不变。
- 客户 `/periodic-budget` 与 `?key=` 行为不变。

选择器只执行 GET。用户明确点击某条目标后，使用 Vue Router 进入对应的规范深链；不自动选择第一项，不把名称当 ID，不在本地保存权限事实。

## 3. 数据与权限

复用现有 admin/finance 列表：

- `GET /api/platform/tenants`：读取 ID、名称和状态；
- `GET /api/platform/procurement-accounts`：通过现有严格 parser 读取 ID、label/provider/state。

使用现有 `readProcurementRows` 游标、活动上下文和上限，两个列表共同成功才显示完整选择；失败显示错误与重试，不能伪装成空目录。按名称和 ID 排序，客户端每页最多 20 条，搜索不请求新权限。

选择器只显示平台角色本就可读取的安全字段，不显示钱包金额、凭据、渠道、原始错误或模型正文。租户暂停、采购暂停等状态仍展示，不据此放宽后续服务端权限。

## 4. UI 与故障

- 显示加载、空、错误、可搜索列表和客户端分页；空目录仅向 admin 提供客户/采购账户原页面入口，finance 角色显示联系管理员指引，不展示无权限动作。
- 身份变化、离开页面和新读取使旧响应失效；旧请求的 401 不得通过全局认证事件清除新会话，也不把旧列表套到新身份。
- 目标行使用响应式卡片显示类型、名称/供应商标识、状态、规范 ID 和“查看预算”操作；390px 下按钮可见且可通过真实指针点击，长名称/ID 可换行，无整页横向溢出。

## 5. 验收

1. `parsePeriodicTarget` 原有严格解析测试保持；空平台路径仍不伪造 target，由视图显式进入选择器。
2. 选择器测试覆盖分页、游标重复、错误非空、空目录、搜索与客户端分页的实际行、深链生成、无效查询分支和旧响应/旧 401 淘汰。
3. 真实浏览器使用至少两个目标验证过滤，在桌面和 390px 检查选择器自身布局并截图，再以 CDP 指针点击可见卡片按钮，确认 URL 的 tenant ID 与预算面板；无账户环境显示空态而非错误。
4. 运行前端全套测试/严格构建、相关 Go/架构检查和完整 029 非回归；新代码提交独立 PR，不影响体验实例或其他分支。

## 6. 非目标

- 不新增全局预算事实、跨租户汇总、第二套权限或后端 API。
- 不接入正式支付商，不改变 sandbox/payment 文案。
- 不自动选择租户、绕过授权、修改周期预算写操作或原操作 journal。
