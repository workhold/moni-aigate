上游行为参考仅包括固定 New API `e449cc7` 的声明式分组、当前路由展开、偏好记忆和移动导航原语；不以源码时长宣称实际流畅度。

## 2. 单一导航模型与分组

`web/src/navigation.ts` 声明组、路径和顺序；`App.vue` 先按现有角色条件生成链接，再由 `groupPlatformLinks` 分组：

- 空组不显示；未分组或重复路径配置直接报错，防止新页面悄悄消失。
- 当前路由所在组自动展开，其余组保留用户选择；用户展开状态仅写入当前浏览器会话的 `sessionStorage`。
- 偏好键只接受已知组 ID 和布尔值；坏 JSON、超长或未知字段不生效。偏好不是权限事实。
- 周期预算直链必须显示资金组中的真实当前项，不能把其他平级业务页伪装成选中。

## 3. 滚动与视觉

- 品牌和底部运行状态固定，只有 `.sidebar-nav` 独立纵向滚动。
- 路由变化和移动抽屉打开后，当前链接使用 `block:nearest` 滚入可视区。
- 主链接字号和选中对比不压缩；组标题提高可读性，移动触控行高约 44px。
- 折叠 chevron 使用小幅 180ms 动效；`prefers-reduced-motion: reduce` 时关闭侧栏/分组动画和滚动平滑效果。
- 不通过进一步缩小字体、删除功能或全局换肤解决数量问题。

## 4. 移动端可访问性

800px 以下使用现有左侧抽屉：

- 顶栏按钮具有 `aria-expanded`/`aria-controls`；抽屉打开时侧栏不再 inert，关闭时 inert。
- 打开后焦点进入显式“关闭导航”按钮；Tab/Shift+Tab 只在抽屉当前可见控件内循环。
- Escape、关闭按钮、遮罩和导航选择均可关闭；关闭后焦点返回顶栏触发按钮。
- 打开时锁定背景滚动，关闭/卸载时恢复原值。
- 关闭状态隐藏链接不得进入键盘焦点顺序；断点切换不得遗留背景锁。
