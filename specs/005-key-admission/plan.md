# 005 实施计划

1. 固定修改前普通容量测试binary；记录既有完整链路的环境和负载口径。
2. 实现零值可用、有界的按Key FIFO票据与取消/幂等释放；只在server编排挂接，不修改billing/routing事务。
3. 验证FIFO、不同Key、取消交接、上限/空队列回收；真实PG验证排队不占池/渠道、排队撤权无预占/派发、长流不持准入票据、幂等与安全重试及probe原有语义。
4. 正确性race通过后停止其他编译/测试/浏览器操作，用固定前后binary交替三对100并发完整商业负载，排队时间计入原测量。无收益回滚；有收益保留并更新HLD/LLD和容量记录。
5. 受影响全量回归、vet/编译后更新本地预览，保存实际值与目标资源/持续竞品尚未验证的边界。
