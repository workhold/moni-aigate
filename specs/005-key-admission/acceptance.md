# 005 验收

| ID | 判据 |
|---|---|
| KA-01 | 同Key按登记顺序交接，不同Key独立；取消首/中/尾等待者不阻塞后继，交接与取消竞争无泄漏，重复释放安全。 |
| KA-02 | 每Key含持有者最多16票，空Key拒绝、空队列回收；运行global/tenant/key许可仍覆盖所有等待者。 |
| KA-03 | 等待无PG连接或事务、无渠道/半开许可；取消预占前request/reservation/POST均0。 |
| KA-04 | 排队期间撤Key/成员模型授权，获票后真实新权限查询拒绝，无未授权POST；原资金/撤权与实例失锁回归继续通过。 |
| KA-05 | 上游长流开始后准入票据已释放，同Key后继可准入；渠道/全局流许可在实际执行结束后释放，取消与交付失败无残留。 |
| KA-06 | 同Key幂等仍由原持久约束决定；安全重试重新排队，至多两POST且未消费判据不变，probe保留原限制。 |
| KA-07 | 固定前后binary，交替三对，保留每轮TTFB/TTFC/p99/成功/POST/账本/冻结/资源结果。无稳定收益回滚，不从开销中扣除排队。 |
| KA-08 | Plan.Start的admit回调panic保留原panic，归还尚未转交的渠道/half-open许可、attempt计数不增加；后继仍能准入，成功转交的执行许可不提前释放。 |

每项执行事实与未覆盖部分汇入新的性能验证记录，不因为局部优化低于50ms就认定目标资源或正式竞品对齐完成。
