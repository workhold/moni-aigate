## 实现范围

人工核款、运营赠额、支付capture和非现金opening经同一ApplyFundingTx建立不可变来源；Reserve FIFO分配、finish按原边收费/释放、ApproveRefund逆原charged边退款，都在原事务内维护来源余额、事件及分配。023正式迁移与最小APP/worker/projector权限、离线开账与只读核对命令、来源与请求分配HTTP、钱包/请求/平台控制台已接通。

开账仅支持停止服务的未使用空钱包；旧金融历史拒迁并保留原件，使用独立当前新库。没有自动历史转换/双运行，也没有真实原路现金退款/拒付。客户消费退款不恢复Key或周期spent。026经营报表继续统计唯一收入、退款和全部attempt成本；opening不算模型销售收入。
